# 5in Test Mules

Experimental 5-inch quadcopter development platform focused on rapid iteration, distributed ESC layouts, propulsion experimentation, and low-cost UAV prototyping.

## Current Configuration

- 5-inch carbon fiber frame
- Staggered arm geometry
- A2212/5T 2450KV outrunner motors
- 30A ESCs mounted along arms
- Central PDB layout
- Underslung 3S LiPo battery
- Open center stack for avionics expansion

## Design Goals

- Improve airflow separation
- Reduce wiring congestion
- Simplify troubleshooting
- Maintain modular avionics access
- Develop practical multicopter engineering skills

## Planned Testing

Initial propulsion testing will use a servo tester before flight controller integration.

Testing includes:
- ESC startup validation
- Direction verification
- Throttle response analysis
- Heat monitoring
- Loaded propeller testing

## Future Expansion

Potential additions:
- FPV system
- Telemetry
- AI-assisted diagnostics
- Alternative propulsion configurations
- Autonomous functions
- Vibration isolation systems

## Philosophy

This project intentionally embraces parts-bin engineering and practical experimentation over polished presentation.

Built to learn.
Built to test.
Built because sitting still is overrated.
